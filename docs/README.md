# Welcome to STELLAR-PATH
**STELLAR-PATH** is a deterministic repository intelligence toolchain designed for the Stellar and Soroban smart contract ecosystems.
### Flagship Tools
* **`stellarpath-cli`**: High-performance static analysis CLI that detects Soroban contracts, maps authorization hierarchies (`require_auth`), and inspects storage tiers.
* **`stellarpath-action`**: Automated PR inspection tool that comments architecture reports directly into GitHub pull requests.
* **`stellar-scaffold`**: Architectural project bootstrapper for standardized Soroban workspaces.
