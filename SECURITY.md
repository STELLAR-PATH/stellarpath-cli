# Security Policy

## Supported Versions

Currently, only the latest release of `stellarpath-cli` receives security updates.

## Reporting a Vulnerability

We take security issues very seriously. If you discover a security vulnerability within StellarPath, please do NOT disclose it publicly.

Instead, please send an email directly to the maintainers or use GitHub's private vulnerability reporting feature (if enabled).

Upon receiving a vulnerability report, we will:
1. Acknowledge the receipt of your report within 48 hours.
2. Investigate the issue and determine its validity and severity.
3. Work with you to resolve the vulnerability.
4. Release a patch or update to address the issue.
