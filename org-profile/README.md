# STELLAR-PATH

**Deterministic developer tooling and cognitive onboarding aids for the Stellar and Soroban ecosystems.**

## Our Mission

At STELLAR-PATH, we believe that onboarding into a new ecosystem shouldn't feel like navigating a maze. Our mission is to build intelligent, static-analysis driven tools that reduce cognitive overload, eliminate cold-start latency, and guide developers precisely where they need to go.

## Core Repositories

- [**stellarpath-cli**](https://github.com/STELLAR-PATH/stellarpath-cli): The core CLI engine that deterministically scans Stellar/Soroban monorepos, classifies their architecture, and recommends starting points.

## Roadmap

- **v0.1:** AST-based deterministic scanning and terminal rendering (Completed).
- **v0.2:** Authorization flow graphs, custom plugin support, and developer telemetry.
- **v0.3:** IDE integrations (VSCode / IntelliJ) and broader ecosystem template detection.
