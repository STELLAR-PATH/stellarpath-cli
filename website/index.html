STELLAR-PATH
Overview Why this exists What it detects Usage Output Limitations
A deterministic repository intelligence CLI

Analyze Stellar and Soroban workspaces

Offline static analysis for SEP implementations, Horizon usage, and common smart contract vulnerabilities.

Why this exists

When confronting unfamiliar Stellar or Soroban repositories, developers lack a deterministic starting point. StellarPath exists to instantly map project structures, flag outdated SDK usage, and identify common smart contract anti-patterns before you even start coding.

What it detects

Soroban Contract Detection

Triggered by the presence of #[contract] or #[contractimpl] attributes within Rust source files.

RPC vs. Horizon Usage

Triggered by analyzing JS/TS/Go/Py/Rs source code for legacy Horizon endpoints (horizon.stellar.org) versus modern RPC initializations (rpc.Server).

SEP Implementation (SEP-10, SEP-24, SEP-53)

Triggered by specific challenge transaction methods, interactive endpoint URLs, or explicit text references indicating the adoption of Web Auth, Hosted Deposit/Withdrawal, and Sign-In with Stellar.

Security Linting (3 specific mistakes)

Triggered by static patterns representing bare panic! without typed errors (Mistake #17), unsafe unwrap() or expect() (Mistake #18), and missing event publishing statements (Mistake #19).

Usage & Integration

Local Installation

Install directly via Cargo (requires Rust toolchain):

cargo install --path .

Run the analysis on your workspace:

stellarpath scan .
stellarpath lint .

GitHub Actions Integration

You can use the official GitHub Action in your CI pipeline:

steps:
  - uses: actions/checkout@v4
  - name: Run StellarPath Analysis
    uses: STELLAR-PATH/stellarpath-action@v1

Real Terminal Output

Here is the exact terminal output from running the CLI's lint mode on a project with security mistakes:

$ stellarpath lint .
Security Lint Findings:
- testdata/soroban-project/src/lib.rs [SorobanContract]: Mistake #19 (Missing events): No event publishing found in contract
- testdata/lint-project/src/contract.rs [SorobanContract]: Line 2: Mistake #17 (Bare panic! instead of typed errors)
- src/lint.rs [SorobanContract]: Line 46: Mistake #18 (Unsafe unwrap() / expect())

Limitations & Scope

StellarPath aims for deterministic precision over broad assumptions. As such, it intentionally does not do the following:

  • Detect all 23 Soroban security mistakes (currently only detects 3).
  • Perform deep control-flow or heuristic analysis for logic bugs.
  • Identify SEPs beyond SEP-10, SEP-24, and SEP-53.
  • Execute or fuzz smart contracts (static analysis only).
  • Create or deploy contracts (use stellar-scaffold for generation).
